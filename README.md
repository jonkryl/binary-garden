# Binary Garden / Двоичный сад

An original offline binary logic puzzle for Android 7+. Two board sizes (6×6, 8×8), a UTC daily puzzle, automatically saved free and daily progress, undo, independent solution checks and hints derived from legal row/column completions. RU/EN, no account, no backend or in-app purchases. Yandex banner ads; contextual default, personalization choice never disables advertising.

CI compiles once, tests the generator against an independent bounded solver, lints, then exercises Android API24/36 using the same APKs. Hosted jobs and signed artifacts are recorded by exact source SHA. Production uses a real own ad ID and a protected upload key. No private inputs belong in this repository.
